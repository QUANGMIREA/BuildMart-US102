# User Story US-102 — Отображение единицы измерения товара

**Родитель:** Epic «Каталог строительных материалов» -> Feature «Отображение товаров».

**История:** Как покупатель интернет-магазина строительных материалов, я хочу видеть цену и единицу измерения товара, чтобы правильно рассчитать объём и стоимость покупки.

**Приоритет:** High. **Размер:** 3 story points (учебная оценка).

## Acceptance Criteria

- AC1: GET /products возвращает `id, sku, name, price_rub, unit` для каждого товара.
- AC2: У «Цемент М500» единица «мешок», у «Песок» — «м³».
- AC3: GET /products?unit=мешок выдаёт только товары с соответствующей единицей.
- AC4: GET /products/999 отвечает HTTP 404.
- AC5: Миграция V002 обновляет существующие тестовые товары без потери данных и повторно не применяется.
- AC6: Автоматические тесты и code review пройдены; ручной TC-102 выполнен до разрешения выпуска.
- AC7: Недопустимая единица, попавшая в БД, обнаруживается проверкой, а не молча выводится пользователю.
