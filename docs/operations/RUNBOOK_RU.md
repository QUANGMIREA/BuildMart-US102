# Runbook (demo)

1. Проверить /health и Azure Pipelines Run.
2. Проверить применённые миграции в `schema_migrations`.
3. При отказе каталога остановить расширение pilot и зарегистрировать инцидент.
4. Перед восстановлением оценить различия в структуре данных; rollback контейнера не возвращает схему БД назад.
5. Уведомить PM/QA, провести smoke test и задокументировать результат.
6. По business continuity следовать `BCP_RU.md`.
