# Release Checklist BuildMart v1.0.0 (шаблон)

- [ ] User Stories в объёме релиза соответствуют Acceptance Criteria.
- [ ] Все PR прошли сторонний review и build validation.
- [ ] Все применимые migrations проверены на копии данных.
- [ ] Автоматические тесты и coverage threshold пройдены.
- [ ] Ручной тест TC-102 выполнен и записан.
- [ ] Нет открытых блокирующих или критических багов.
- [ ] Release Manager зафиксировал решение о выпуске.
- [ ] Готовы Release Notes и rollback/restore plan.
- [ ] Build artifact и tag указывают на один исходный commit.
- [ ] Развертывание выполнено, smoke test подтвержден, Deployment Record заполнен.

**Не отмечайте пункты до фактического выполнения.**
