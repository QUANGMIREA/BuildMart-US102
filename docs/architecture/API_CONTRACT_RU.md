# API Contract BuildMart demo

| HTTP | URL | Описание | Основные проверки |
|---|---|---|---|
| GET | `/health` | Ответ `{"status": "ok"}` | Smoke test |
| GET | `/products` | Список `id, sku, name, price_rub, unit` | Авто + ручной TC-102 |
| GET | `/products?unit=мешок` | Фильтр по единице | Авто + ручной TC-102 |
| GET | `/products/{id}` | Один товар / 404 | Авто |

Норматив единиц: `шт.`, `кг`, `т`, `м³`, `мешок`. Некорректная единица в БД приводит к ошибке 500 (нужна диагностика и исправление данных). В production также необходимы аутентификация, мониторинг, rate limiting и требования безопасности.
